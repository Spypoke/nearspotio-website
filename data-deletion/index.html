Data Deletion Request / Datenlöschung

Stand: 3. April 2026

Welche Daten erhebt NearSpotio?

NearSpotio erhebt keine Namen, E-Mail-Adressen oder Benutzerkonten.

Die App verwendet Firebase-Dienste (Analytics und Crashlytics) zur Speicherung pseudonymer Nutzungsdaten, wie z. B. Funktionsnutzung, Sitzungsdaten und technische Diagnosedaten. Diese Daten sind mit einer zufälligen App-Installations-ID verknüpft. Firebase kann dabei auch technische Gerätekennungen verarbeiten.

Zusätzlich verarbeitet Google AdMob (Werbung) Werbe-Identifikatoren (IDFA / Advertising ID) auf eigenen Servern von Google.

Für das Trial-System wird eine gehashte Geräte-ID (SHA-256) in Google Cloud Firestore gespeichert, zusammen mit Plattform, Registrierungszeitpunkt, Ablaufdaten und Export-Zähler.

So beantragst du die Löschung deiner Daten

Wenn du möchtest, dass alle mit deiner App-Installation verknüpften Daten gelöscht werden, gibt es zwei Möglichkeiten:

Option 1: Direkt in der App (empfohlen)

  1. Öffne die NearSpotio-App
  2. Gehe zu Einstellungen → Info
  3. Tippe auf „Meine Daten löschen“
  4. Bestätige die Löschung im Dialog

Zur Verhinderung von Missbrauch der Testphase wird die pseudonyme Gerätekennung sowie der Testphasen-Status auch nach Löschung beibehalten. Nach der Löschung werden nur noch die für die Testphasen-Verwaltung notwendigen Daten gespeichert.

Option 2: Per E-Mail

  1. Öffne die NearSpotio-App
  2. Gehe zu Einstellungen → Info
  3. Kopiere deine App-Installations-ID
  4. Sende diese ID per E-Mail an:

Wir werden alle mit dieser ID verknüpften Daten aus unseren Systemen löschen.

Was wir löschen können

Folgende in Firebase (Google) gespeicherte Daten, die mit deiner Installations-ID verknüpft sind:

  • Pseudonyme Nutzungsstatistiken (Firebase Analytics)
  • Absturz- und Diagnosedaten (Firebase Crashlytics)
  • Nutzungsdaten in Cloud Firestore (gehashte Geräte-ID, Ablaufdaten, Export-Zähler, Pro-Status, App-Starts, Spracheinstellung)

Was wir nicht direkt löschen können

Werbe- und AdMob-Daten: Google verarbeitet Werbe-Identifikatoren (IDFA / Advertising ID) als eigener Verantwortlicher bzw. Empfänger. Diese Daten können nicht über uns gelöscht werden. Du kannst sie jedoch selbst steuern:

  • Werbe-ID in den Geräteeinstellungen zurücksetzen (Android: Einstellungen → Google → Werbung; iOS: Einstellungen → Datenschutz → Tracking)
  • Personalisierte Werbung deaktivieren in den Geräteeinstellungen
  • Unter iOS das Tracking über den ATT-Dialog ablehnen
Nach der Löschung wird bei der nächsten Nutzung der App automatisch eine neue Installations-ID erstellt. Bereits aggregierte und vollständig anonymisierte Statistiken (z. B. Gesamtanzahl der App-Starts) können nicht einzeln entfernt werden, da sie keiner Installation zugeordnet sind.

Hinweis für iOS-Nutzer

Auf iOS wird die gehashte Geräte-ID zusätzlich im Keychain des Geräts gespeichert. Diese Daten überleben eine Deinstallation der App. Um die Keychain-Daten vollständig zu entfernen, musst du das Gerät auf Werkseinstellungen zurücksetzen (Einstellungen → Allgemein → iPhone übertragen/zurücksetzen) oder die App vor der Deinstallation über Einstellungen → Allgemein → iPhone-Speicher → NearSpotio → App löschen entfernen. Alternativ kannst du uns per E-Mail kontaktieren, damit wir die serverseitigen Daten zu deiner ID löschen.

What data does NearSpotio collect?

NearSpotio does not collect names, email addresses, or user accounts.

The app uses Firebase services (Analytics and Crashlytics) to store pseudonymous usage data such as feature usage, session data, and technical diagnostics. This data is linked to a random App Installation ID. Firebase may also process technical device identifiers.

Additionally, Google AdMob (advertising) processes advertising identifiers (IDFA / Advertising ID) on Google's own servers.

For the trial system, a hashed device ID (SHA-256) is stored in Google Cloud Firestore, along with platform, registration timestamp, expiry dates, and export counter.

How to request deletion of your data

If you want all data associated with your app installation to be deleted, there are two options:

Option 1: Directly in the app (recommended)

  1. Open the NearSpotio app
  2. Go to Settings → Info
  3. Tap "Delete my data"
  4. Confirm the deletion in the dialog

To prevent abuse of the trial period, the pseudonymous device identifier and trial status are retained even after deletion. After deletion, only the data necessary for trial management will be stored.

Option 2: Via email

  1. Open the NearSpotio app
  2. Go to Settings → Info
  3. Copy your App Installation ID
  4. Send this ID via email to:

We will delete all data associated with this ID from our systems.

What we can delete

The following data stored in Firebase (Google) that is linked to your Installation ID:

  • Pseudonymous usage statistics (Firebase Analytics)
  • Crash and diagnostic data (Firebase Crashlytics)
  • Usage data in Cloud Firestore (hashed device ID, expiry dates, export counter, Pro status, app launches, language setting)

What we cannot directly delete

Advertising and AdMob data: Google processes advertising identifiers (IDFA / Advertising ID) as a separate data controller/recipient. This data cannot be deleted through us. However, you can manage it yourself:

  • Reset your advertising ID in your device settings (Android: Settings → Google → Ads; iOS: Settings → Privacy → Tracking)
  • Disable personalized advertising in your device settings
  • On iOS, deny tracking via the ATT dialog
After deletion, a new Installation ID will be created automatically the next time you use the app. Aggregated, fully anonymized statistics (e.g. total number of app launches) cannot be individually removed, as they are not tied to any specific installation.

Note for iOS Users

On iOS, the hashed device ID is additionally stored in the device's Keychain. This data survives app uninstallation. To fully remove the Keychain data, you need to reset the device to factory settings (Settings → General → Transfer or Reset iPhone) or remove the app via Settings → General → iPhone Storage → NearSpotio → Delete App before uninstalling. Alternatively, you can contact us via email so we can delete the server-side data associated with your ID.
